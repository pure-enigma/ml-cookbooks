# crisp_dm

The project plan `<project-plan>` is the primary record of this project's progress. Read it before substantial work and keep it updated as understanding, decisions, or the current phase change.

It guides progress through problem understanding, data understanding, data preparation, modeling, evaluation, and delivery. Track the current phase, unresolved questions, and readiness to move to the next phase there. Follow its phase-specific prompts and checks, discuss progression with the human, and revisit earlier phases when findings require it—not a rigid waterfall.
